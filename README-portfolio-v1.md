# UXGyan — Minimal portfolio v1

Minimal editorial homepage built with HTML, CSS and vanilla JavaScript. No build step required.

## Preview
Open `index.html` in a browser.

## Files
- `index.html` — hero and four-project gallery
- `styles.css` — responsive layout and CSS-only illustrative artwork
- `script.js` — mobile navigation and current-year footer
- `about.html` — short professional introduction

## Before publishing
1. Replace CSS-built illustrative artwork with approved project screenshots.
2. Confirm email and add the correct LinkedIn URL.
3. Complete the project pages under `projects/` and verify links.
4. Check all role claims, metrics and project descriptions for accuracy and confidentiality.
5. Clearly label Uber as independent research, not commissioned work.
